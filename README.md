## A simple remake of Hangman in C++
Try to guess a word, letter by letter, in less than 6 wrong attempts!
```
_____________________
|  /                |          GGGGGG     LL        HH    HH   FFFFFFFFFFF     !!
| /                 |         GGG         LL        HH    HH   FFFFFFFFFF      !!
|/                  |         GG          LL        HHHHHHHH   FF              !!
|                 /x x\       GG   GGGG   LL        HHHHHHHH   FFFFFF          !!
|                 \_-_/       GGG    GG   LLL       HH    HH   FF                
|                  /|\         GGGGGGG    LLLLLLL   HH    HH   FF              !!
|                 / | \
|                  / \
|                 /   \       ****************************************************
|                             /\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\/\
```

Haven't learnt CMake yet, so it's currently fully compatible with just Visual Studio.
You very well could plop the [main.cpp file](https://github.com/FSFlavi/HangmanGame/blob/master/HangmanGame/main.cpp) into the IDE of choice, it's the only necessary file and small enough to work well.
